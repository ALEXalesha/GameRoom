# Общее для оболочек-ОС (win11_3, macos-tahoe, ios26, oneui7)

## Таблица игр: games.js

`games.js` - одна таблица игр «Игротеки» для всех оболочек. Окно игры открывает соседнюю папку
репозитория `../<dir>/index.html`, то есть полную версию игры.

Название игры берётся из самой игры. Каждая игра объявляет его в `<head>`:

```html
<meta name="application-name" content="Дино-бег">
```

Скрипт `node web/_os-shared/build-games.js` читает эти метки и переписывает названия в таблице.
Закон в tests/web/win11_3.spec.js сверяет таблицу с метками и падает с понятным текстом, если метки нет.

## Протокол паузы: оболочка ↔ игра

Игра в окне оболочки живёт в `<iframe>`. Скрыть вкладку браузера оболочка не может, а свёрнутое окно
для iframe остаётся видимым: без протокола игра крутит кадры и звук в свёрнутом окне.

**Оболочка → игра** (через `iframe.contentWindow.postMessage(..., '*')`):

| Сообщение | Когда |
|---|---|
| `{ mix: 'pause' }` | окно свернули, закрывают, окно потеряло фокус (стало активным другое), телефон ушёл «Домой» или в переключатель программ |
| `{ mix: 'resume' }` | окно снова развернули или сделали активным, телефон вернулся в игру |

Что делает игра:

- на `pause` - ведёт себя как при скрытой вкладке: останавливает игровое время, анимацию и звук;
- на `resume` - **пауза остаётся**, игра показывает своё меню паузы, снимает паузу игрок (щелчок, клавиша);
- по желанию отвечает оболочке `parent.postMessage({ mix: 'paused' }, '*')` - так проверки видят, что игра услышала.

Игра, которая поддерживает протокол, объявляет это меткой:

```html
<meta name="mix-protocol" content="pause">
```

Пример для игры:

```js
addEventListener('message', (e) => {
  const m = e.data && e.data.mix;
  if (m === 'pause') { pauseGame(); if (parent !== window) parent.postMessage({ mix: 'paused' }, '*'); }
  if (m === 'resume') showPauseMenu();          // игрок сам нажмёт «Продолжить»
});
document.addEventListener('visibilitychange', () => { if (document.hidden) pauseGame(); });
```

Проверочная игра-заглушка `pause-stub.html` делает ровно это и считает кадры: по ней законы оболочек
измеряют, что в свёрнутом окне игровое время стоит.
