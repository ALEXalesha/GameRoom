# Horizon Drift - ход работы (ветка drift)

Цель: web/horizon_drift_offline - законченная гонка: карьера 5 кубков, 8 трасс, 8 машин, гараж, ИИ, настройки.

## Сделано
- js/data.js - машины (8), тюнинг (таблица), покрытия, трассы (8, «черепашкой»), темы, кубки (5), клавиши, настройки.
- js/core.js - построение трасс (замыкание кольца, гоночная линия, кривизна), физика машины (увод шин, круг трения,
  ручник, нитро, АБС, антипробуксовка, коробка), дрифт-очки, ИИ (линия, профиль скорости, обгон, ошибки, догонялки),
  заезд (сетка, чекпоинты, круги, стены, столкновения, на вылет, итог), карьера (медали, деньги, покупки, тюнинг),
  настройки (слияние, переназначение с конфликтом). Работает в node: scratchpad/dev/bots.js гоняет бота по всем трассам.
