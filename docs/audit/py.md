как защита от старой ошибки.

## Общие законы окон

- Проверки идут без экрана: `QT_QPA_PLATFORM=offscreen` и `QT_QPA_FONTDIR=C:\Windows\Fonts`
  (без шрифтов буквы превращаются в квадраты). Одна `QApplication` на весь прогон
  через фикстуру `qapp` в `tests/py/conftest.py`.
- Подписи с переносом (`wordWrap`) не ограничены по высоте. В окне минимального
  размера со шрифтом на 10% крупнее их текст помещается целиком (`tests/py/qt_laws.py`).
  Это проверяется у всех шести программ.
- Данные программ в проверках пишутся только во временную папку. Настоящая Корзина
  в проверках не трогается: вместо неё подставляется функция, которая только
  запоминает, что ей передали.
- Браузер в проверках в интернет не ходит: только локальные файлы и закрытый порт
  на 127.0.0.1.

## Как запустить

```
pip install -r requirements-py.txt
python py/paint.py            # и так же остальные: compiler, telegram_clone, explorer, browser, os_sim
python -m pytest tests/py -q
```

`send2trash` не понадобился: Корзину умеет Qt (`QFile.moveToTrash`).

## Что не проверено

- Живой запуск на экране Алексея. Кадры снимались offscreen. Латинские буквы и
  цифры в таких кадрах выходят узкими (так рисует offscreen), на настоящем экране
  это нужно глянуть глазами.
- Содержимое страниц браузера на кадре: offscreen не снимает то, что рисует
  QtWebEngine. Текст страницы ошибки проверен через `toPlainText`.
- Настоящая отправка в Корзину Windows. В проверках вместо неё подставная
  функция; то, что вызывается именно `QFile.moveToTrash`, проверено подменой.
