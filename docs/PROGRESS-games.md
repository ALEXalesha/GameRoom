# Ход доработки игр для «Игротеки» (ветка fix-games)

Задача владельца: dino, mario («Прыг-скок»), jungle-strike («Огненные джунгли»), space_shooter
(«Космический стрелок») довести до законченных игр. Итог описан в docs/audit/games.md,
раздел «После доработки для «Игротеки»».

Общий каркас: `web/<игра>/kit.js` - одинаковые копии (источник - web/dino/kit.js, после
правки копировать во все четыре папки; одинаковость проверяет tests/web/kit.spec.js).
Помощники проверок: tests/web/_kit-helpers.js, tests/web/_games-helpers.js.

## Сделано
- [x] jungle-strike: огонь ЛКМ (764d6ff)
- [x] dino: 4 этапа до 10 000 м, бесконечный бег; 20 законов, 11 мутантов
- [x] space_shooter: 8 секторов, 4 босса, мастерская, выживание; 18 законов
- [x] jungle-strike: 5 миссий с боссами; 22 закона
- [x] пауза: надписи холста не наезжают на окно паузы, фокус паузу не снимает (166b196)
- [x] mario («Прыг-скок»): 8 уровней в 2 мирах, 2 босса, карта со звёздами, автопилот
      проходит кампанию; 22 закона, 16 мутантов (c4b1929 … 0a08345)
- [x] kit.spec.js; снимки всех четырёх игр при 1280x720 и 1920x1080 просмотрены
- [x] полный прогон: зелёно всё, кроме explorer_1 (чужая страница, Google Fonts без сети)

- [x] ревью четырёх игр: всё исправлено (kit: порченые данные, звук, геймпад, отложенные окна, настройки
      в 700 px; игры: пункты ревью), законы в kit.spec.js и спецификациях игр, мутации пойманы
- [x] честная проходимость: автопилоты Джунглей и Стрелка проходят кампании без неуязвимости
- [x] протокол оболочки {mix:'pause'|'resume'} и meta application-name (4 игры)
- [x] пиксельный шрифт Джунглей (pixel-font.js)

- [x] «Блоки» (web/tetris): 4 режима, SRS, T-вращения, комбо, серия, DAS/ARR/SDF, рекорды; 28 законов, 21 мутант
- [x] «Судоку» (web/sudoku): уровни по приёмам, подсказки с объяснением, ежедневная, темы; 22 закона, 19 мутантов
- [x] снимки шести игр при 1280x720 и 1920x1080 просмотрены; полный прогон зелёный, кроме чужого explorer_1

- [x] второе ревью: Судоку (генератор без null, ярусы уровней, сохранение), Блоки (DAS в кадрах, очередь не зависит от заставки), Джунгли (границы кадра, трудная сложность), kit (сообщения только от родителя); законы и мутации
