# Ход доработки игр для «Игротеки» (ветка fix-games)

Задача владельца: dino, mario («Прыг-скок»), jungle-strike («Огненные джунгли»), space_shooter
(«Космический стрелок») довести до законченных игр: прохождение с финалом, главное меню,
пауза, настройки (громкость музыки и звуков, сложность, переназначение клавиш, геймпад,
графика, сброс прогресса), дизайн, пауза при скрытии вкладки, тесты с мутациями,
снимки в docs/screens/<игра>-*.png, раздел в docs/audit/games.md.

Общий каркас: `web/<игра>/kit.js` - одинаковые копии (источник - web/dino/kit.js, после
правки копировать во все четыре папки). Помощник проверок: tests/web/_kit-helpers.js.
