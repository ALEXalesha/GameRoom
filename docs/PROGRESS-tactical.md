# «Операция: Периметр» (web/fps_1) - ход работы

Ветка `tactical`. Страница `web/fps_1/index.html` + `style.css`, код в `web/fps_1/js/*.js` (обычные скрипты, общий объект `TAC`, работает по file:// без сети). Крючок проверок - `window.__tactical`.

## Сделано
- Меню в духе оригинала с 3D-фоном: Играть (режим → карта → боты → старт), Операция (8 миссий), Инвентарь (облики, 2 кейса с лентой), Статистика, Настройки (Игра, Прицел, Видео, Аудио, Клавиатура и мышь), Выход. Экран загрузки с картой и советом.
- Режимы: соревновательный 5 на 5 (бомба, экономика, 8 из 15 или 13 из 24, смена сторон), бой насмерть, командный бой насмерть, разминка-тир (60 с, рекорд).
- Карты: Карьер, Порт (по две точки A/B), Полигон. Текстуры кодом, запечённый свет пола, небо.
- Боты: закупка, роли, взгляд лучом, реакция и промах по сложности, слух, укрытие, перезарядка, подбор, закладка и обезвреживание, повтор по семени.
- Оружие: 12 стволов + нож + 4 гранаты, урон по зонам и броне, узор отдачи, разброс, прицел.
- HUD, таблица счёта, итоги раунда и матча, звания, кампания с финалом и титрами, пауза при скрытой вкладке.
- Проверки: tests/web/fps_1*.spec.js (42 закона), мутации - 23 из 23 пойманы.

## Замеры (Playwright, 1280x800, 9-10 ботов)
- GPU (RTX 5060 Ti, D3D11): кадр в среднем 4.2 мс, худший 1% - 4.5 мс (соревновательный) и 9.8 мс (бой насмерть); JS на кадр 1.2-1.3 мс.
- Без GPU (SwiftShader в headless): кадр 53-69 мс, JS на кадр 1.8-2.3 мс - упирается в программную отрисовку.

## Можно доделать
- Модели бойцов и оружия - из коробок; анимации простые.
- Боты не бросают светошумовые; дым и зажигалку - изредка.
