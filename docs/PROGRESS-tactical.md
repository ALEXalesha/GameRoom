# «Операция: Периметр» (web/fps_1) - ход работы

Ветка `tactical`. Страница `web/fps_1/index.html`, код в `web/fps_1/js/*.js` (обычные скрипты, общий объект `TAC`).

## Сделано (код написан, ещё не подключён к index.html и не проверен)
- `util.js` - генератор с семенем, хранилище `mix.tactical.*`, математика.
- `data.js` - оружие (узоры отдачи), экономика, сложность ботов, 3 карты (Карьер, Порт, Полигон), облики, кейсы, звания, 8 миссий, настройки по умолчанию.
- `world.js` - сетка карты, ящики, луч (DDA), движение с шагом вверх, A* по клеткам.
- `textures.js` - текстуры и узоры обликов кодом, небо.
- `mapmesh.js` - сетки карты, запечённая карта света (тени солнца + углы), вершинное затенение стен.
- `agents.js` - боец, зоны попадания, модель из коробок.
- `combat.js` - урон по таблице, разброс, отдача, выстрел, нож, взрыв.
- `effects.js` - трассеры, следы, частицы, дым, огонь, бомба.
- `audio.js` - синтез звуков, панорама, шины, музыка меню.
- `match.js` - режимы, раунды, деньги, бомба, гранаты, возрождение, итоги.
- `bots.js` - мозг ботов.
- `profile.js` - настройки, инвентарь/кейсы, статистика, звания, кампания, код прицела.
