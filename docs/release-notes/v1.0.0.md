Igroteka 1.0.0 - ten offline games in one window.

- Ten games in tabs: Cube World, Cube Parkour, 3D Shooting Range, Dino Run, Hop-Skip,
  Horizon Drift, Fire Jungle, Space Shooter, Blocks and Sudoku. No internet needed.
- Each game keeps its own records and saves; they survive a restart and can be cleared
  for one game without touching the others.
- A game you switch away from pauses and goes quiet; switch back and continue.
- Handy keys: Ctrl+T home, Ctrl+W close, Ctrl+Tab next tab, F11 full screen, F5 restart.
- The window opens where you left it, with the same tabs; dark and light themes, app-wide
  volume, and its own icon.
- Installer for one user without admin rights, or a portable exe.

«Игротека» 1.0.0 - десять игр без интернета в одном окне.

- Десять игр во вкладках: «Кубический мир», «Кубик-паркур», «Тир 3D», «Дино-бег»,
  «Прыг-скок», «Horizon Drift», «Огненные джунгли», «Космический стрелок», «Блоки», «Судоку».
  Интернет не нужен.
- У каждой игры свои рекорды и сохранения: они живут после перезапуска, и их можно стереть
  у одной игры, не трогая другие.
- Игра, с которой переключились, встаёт на паузу и замолкает; вернулись - играете дальше.
- Удобные клавиши: Ctrl+T домой, Ctrl+W закрыть, Ctrl+Tab следующая вкладка, F11 во весь
  экран, F5 заново.
- Окно открывается там же и с теми же вкладками; тёмная и светлая тема, общая громкость,
  свой значок.
- Установщик для одного пользователя без прав администратора или portable-файл.
